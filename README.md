# NS2 Seeding Horde Mode

Tower-defense-style seeding minigame for Natural Selection 2 (Spark engine), shipped as a
**published Workshop mod** (`seedinghorde`, item `3807461324`) and integrated with the
[Shine](https://github.com/Person8880/Shine) admin framework.

A marines-only seeding server runs endless bot-alien waves out of procedurally placed tunnel
mouths. Marines can never win; the score is how many waves the server survived.

**New here? Read [`HANDOFF.md`](HANDOFF.md) first** — environment, the rules that must not be
broken, how to run anything, current state, and what to do next.

## Design pillars (locked)

1. Seeding-gated: runs only while marines-only and the seed max is not met; opt-in via `/horde`
   (caller must be a marine, ≥ `MinPlayers`, cooldown respected). `/horde status | stop | restart`.
2. **No win condition** — endless waves; the statistic is waves survived. Loss triggers are i8a's
   to implement (all marines dead simultaneously, or the chair destroyed).
3. Complete teardown: "as if it never existed" — our created set is destroyed and accounted for,
   the bot controller is handed back, **the world is reset before the engine's win switch is
   released, and no player is touched: humans keep the team they chose and land back in warmup**
   (restored 2026-09-28 after one day of the spectator-move amendment; the sanctioned fallback is
   the ready room, never spectator).
4. Hybrid hordes: cheap bulk grunts + recycled virtual-client elites, spawning from tunnel mouths
   placed by the engine's own build rules (`Pathing.GetFlags` → ground snap at the tunnel's
   extents → `CollideCapsule`), selected from a seeded per-wave draw.
5. Last Stand map frame: action around the marine main base; prebuilt hive spots with invincible
   hives, prebuilt alien RTs, marines keep only the main-base RT.
6. Layer on all existing maps: the marine CC at team spawn is the base; per-map config overrides
   via our own `Maps.<mapname>` merge (Shine has no per-map layer).
7. Dual economy: team resources at wave end (intermission only) + personal resources from kills;
   building-kill bounties are one-time and go to the team pool.
8. Wave orchestration is the core system: timings, composition, difficulty.
9. Bezier difficulty methodology: all scaling is computed from curves (bot HP/armor/damage against
   marine DPS/health/reload); warmup → ramp → plateau → post-threshold endless. Admin-tunable
   control points, and the offline visualiser reads the same JSON the server loads.
10. v1 uses vanilla upgrades only. WarmUp grants all tech (RD8), so progression is cost and time.
